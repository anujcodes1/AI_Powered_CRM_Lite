# AI Powered CRM Lite

An intelligent, lightweight Customer Relationship Management (CRM) platform featuring automated lead scoring, AI-generated email drafts, and customer sentiment analytics.

**GitHub Repository:** [anujcodes1/AI_Powered_CRM_Lite.git](https://github.com/anujcodes1/AI_Powered_CRM_Lite.git)

---

## 🛠 Tech Stack

- **Frontend:** Next.js 14 (App Router, TypeScript, Tailwind CSS)
- **Backend:** FastAPI, SQLAlchemy, PostgreSQL
- **AI / LLM Layer:** OpenAI / Gemini API (or local models)
- **Deployment:** Two separate services (Frontend + Backend)

---
